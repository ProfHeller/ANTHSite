Tap any label to rename it. Arrows reorder within a level, the eye hides an item without deleting it, and × removes it. Removing a whole section asks first, since it takes every page under it. Use the buttons at the foot of each group to add pages, or the button at the bottom to add a section. The Site tab updates as you go.

Save or restore your work. Changes live only in this browser tab and are lost on refresh or when a new file is opened.

Each committee member arranges the menu in the Menu editor, then saves it here. Saving writes a small JSON file to their downloads folder, which they email to whoever is collecting layouts. Open those files here to build the comparison. No account, sign-in, or server is involved. A copyable link works too, if email attachments are awkward.
